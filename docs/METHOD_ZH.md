# 方法说明

## 论文名称

QPEF-RAG 的中文含义是“查询感知、来源引导的检索增强生成证据融合”。
源码中保留 QPCF 和 ugcp_v5 作为历史兼容标识。

## 处理流程

1. 多视角生成：得到标准上下文答案、结构化的上下文与先验知识分析结果，
   以及不显示前序答案的核验结果。
2. 查询感知核验：使用密集语义匹配和问题条件化蕴含判断，检查每个候选答案
   是否得到检索文本支持。
3. 证据通道融合：按产生判断的过程组织结果，并设置通道容量，避免同一过程
   产生的多个输出被重复计为多份支持。
4. 保守答案选择：只有当一个候选答案获得唯一且足够的跨通道支持时，才更新
   后备答案；包含显式弃答选项的任务使用更高的支持条件。

知识图谱。通道在操作上彼此区分，但不假设它们在统计上相互独立。
